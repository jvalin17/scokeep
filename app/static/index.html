Scokeep

Score tracker for Judgement (Kachuful) card game

What is Scokeep?

A free mobile app that replaces the notebook when playing Judgement (also called Kachuful). One person runs it on their phone — tap in bids and scores, and the math is done automatically.

Features

  • Phone-style keypad for fast score entry
  • Automatic scoring — bid 0 made = +10, bid 1 = +11, bid N = +N×10
  • Trump suit display and dealer rotation
  • Must-lose mode — forbidden bid greyed out
  • Game modes: Expert, Rookie, Friendly
  • Stats: leaderboard, bid accuracy, trends, awards
  • Works offline — install on your home screen

How to Play Judgement (Kachuful)

Judgement is a trick-taking card game for 3-8 players. Each round, players are dealt cards (8 down to 1), bid how many tricks they'll win, then play. Score points for making your bid, lose points for missing.

How to Use Scokeep

  1. Create a room with a name and 4-digit PIN
  2. Add player names and set the seating order
  3. Choose game mode and settings, then start
  4. Tap bids on the keypad — one player at a time
  5. After the round, tap how many tricks each player won
  6. Scores are calculated automatically
